The reader is a non-technical branch operations head. Score 1 if the update explains the problem by its effect
on customers or branches (for example customers not receiving the confirmation code when booking) rather than
only in technical terms, states that there is no extra cost or what the reader gains by approving, and is
polite rather than commanding. English technical terms such as OTP, UAT or go-live are fine. Score 0 if the
problem is described only in technical jargon, or the tone is commanding.
